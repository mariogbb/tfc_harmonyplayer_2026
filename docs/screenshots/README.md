# Website screenshots

These twelve PNGs show dashboard, album and song content at desktop and mobile
sizes, in light and dark themes. Filenames use the format
`device-theme-screen.png`.

The views are rendered from isolated test fixtures, not captures of the full
application shell. They contain example song names and original abstract
artwork, not official album covers or audio. Review usage rights before
publishing. See `test/screenshot_fixtures/README.md` for regeneration.

The `deezer/` subdirectory contains another set captured from the actual
`HomePage` shell using sample data and covers retrieved from Deezer. These
images contain third-party album artwork; permission and applicable Deezer terms
must be checked before using them on a public site.
